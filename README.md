# Biscuits

A 2D action game made with Godot. Move around the arena, fight enemies, and collect upgrades.

## Run

Use Godot 4.4 or later. Import `project.godot` in the Godot project manager, open the project, and press F5 to run the game.

From a terminal with Godot on your path:

```sh
godot --path . --editor
godot --path .
```

Move with W, A, S, and D. Pause with Escape or P.
